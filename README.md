# Велотрекер

Лёгкий велотрекер-PWA: без сервера и регистрации, данные живут на телефоне, карта
Gran Buenos Aires работает офлайн. Стиль — «Platinum» из Familia Inteligente.

## Что умеет

- Дистанция, время в движении и общее, текущая / средняя / максимальная скорость
- Автопауза (стоим дольше 5 с медленнее 3 км/ч — таймер стоит)
- Автоотрезки (1/2/5/10 км) и ручной отрезок
- Голос: сводка каждые N км, «Пауза»/«Поехали», потеря GPS, итог поездки, новые рекорды
- Калории по формуле MET (вес — в настройках)
- Карта во время поездки и трек, раскрашенный по скорости, после
- График скорости по дистанции (палец по графику — точка на карте)
- История по месяцам, статистика (неделя / месяц / год / всё), личные рекорды
  (дистанция, время, средняя, максимум, лучшие 1/5/10/20/40 км, лучшая неделя и месяц)
- Экспорт GPX, резервная копия и восстановление (JSON)
- Импорт GPX из Open GPX Tracker и других приложений: можно выбрать всю папку,
  уже загруженные поездки пропускаются
- Восстановление записи, если вкладка закрылась посреди поездки
- Блокировка экрана от случайных касаний, «Стоп» — удержанием

## Требования

iPhone с iOS 16.4 или новее (iPhone 8 обновляется до 16.7). Приложение должно
открываться по **HTTPS** — иначе Safari не даст доступ к GPS.

Во время поездки экран должен оставаться включённым (приложение само не даёт ему
погаснуть): браузер на iPhone не пишет GPS при выключенном экране.

### Запись в фоне через Open GPX Tracker

Если телефон в кармане, трек пишет Open GPX Tracker, а велотрекер его разбирает:

1. В Open GPX Tracker сохраняйте треки (GPX) в одну папку в «Файлах».
2. В велотрекере — «Загрузить треки GPX» (на главной или в истории), в папке
   «Выбрать» → «Выбрать все» → «Открыть».
3. Новые поездки добавятся и пересчитаются (автопауза, отрезки, рекорды);
   те, что уже есть, пропустятся.

## Публикация (GitHub Pages, бесплатно)

1. Создать репозиторий на GitHub и загрузить в него содержимое этой папки
   (кроме `.claude/`).
2. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
3. Через минуту приложение будет по адресу `https://<логин>.github.io/<репозиторий>/`.
4. На iPhone открыть адрес в Safari → «Поделиться» → «На экран „Домой“».
5. В приложении: Настройки → «Скачать карту» (≈ 20 МБ, лучше по Wi-Fi).

Подойдёт любой статический хостинг с HTTPS (Netlify, Cloudflare Pages).

## Обновление приложения

После правок файлов увеличьте `VERSION` в `sw.js` — иначе телефон продолжит
открывать старую версию из кэша.

## Локальная проверка

```bash
python3 -m http.server 8765
```

Открыть `http://localhost:8765/?sim=10` — симулятор поездки по Палермо
(в 10 раз быстрее), GPS не нужен. На localhost сервис-воркер отключён;
`?sw=1` включает его для проверки офлайна.

## Карта

`map/gba.bin` — вырезка из ежедневной сборки [Protomaps](https://protomaps.com)
(данные © участники OpenStreetMap, ODbL): Gran Buenos Aires до уровня z14 и обзор
области до z9. Формат: `[u32 длина индекса][JSON-индекс][gzip-тайлы]`. Шрифты и
спрайты — из `protomaps/basemaps-assets`, отрисовка — MapLibre GL 4.7.1.
